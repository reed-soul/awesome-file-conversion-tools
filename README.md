# Awesome File Conversion Tools

A curated list of free online file conversion and processing tools. All tools listed here are browser-based — no installs required.

## 3D File Converters

- [STLMesh](https://stlmesh.com) — Convert between STL, OBJ, FBX, GLTF, 3DS, PLY formats
- [3D Viewer Online](https://3dviewer.net) — View and convert 3D models online
- [Aspose 3D](https://products.aspose.app/3d/conversion) — Online 3D file format converter

## Image Tools

- [ImgFlow](https://imgflow.taoliapp.com/en/) — Browser-based PNG/JPG/HEIC/WebP/AVIF compressor and converter; core processing stays on-device
- [SetDPI](https://setdpi.com) — Change image DPI without quality loss
- [Squoosh](https://squoosh.app) — Image compression by Google
- [TinyPNG](https://tinypng.com) — Smart PNG and JPEG compression

## Email Tools

- [EMLTool](https://emltool.com) — Open and read .eml email files in your browser

## Calendar Converters

- [CSV to ICS](https://csvtoics.app) — Convert CSV spreadsheets to calendar files

## Contact Converters

- [CSV to VCF](https://csv-to-vcf.com) — Convert CSV to vCard contact files

## Creative Tools

- [ColoringPageNook](https://coloringpagenook.com) — Free printable coloring pages with online coloring tool
